# House Price Prediction Using ANN

A web application that predicts median house prices using an Artificial Neural Network trained on the California Housing dataset.

## Features

- Artificial Neural Network regression model
- One-Hot Encoding for Ocean Proximity
- MinMaxScaler preprocessing
- Flask web application
- Responsive HTML/CSS interface
- Real-time house price prediction

## Model Architecture

- Input: 13 features
- Dense Layer: 1000 neurons, ReLU
- Dense Layer: 500 neurons, ReLU
- Dense Layer: 250 neurons, ReLU
- Output Layer: 1 neuron, Linear activation

## Technologies Used

- Python
- TensorFlow / Keras
- Scikit-learn
- Flask
- NumPy
- HTML
- CSS
